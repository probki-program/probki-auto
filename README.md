# Сайт «Пробки»

В корень репозитория публикуются index.html, thanks.html, privacy.html, FONT-LICENSE.txt, README.md и .nojekyll. GitHub Pages: main, /(root).

С 14.11.2026 форма заменена блоком прямой связи через probkiauto@gmail.com. Кнопки «Обсудить подключение» открывают контакты. Ссылка mailto открывает почтовое приложение посетителя; сайт не отправляет заявку и не подтверждает доставку письма.

SmartCaptcha, запросы к Cloud Functions и сохранение заявок из сайта удалены. Сторонние скрипты не подключаются. Файл thanks.html оставлен для старых ссылок и показывает контакты без сообщения об успешной отправке.

Для изменений редактируйте исходники и запускайте build.py через Python из .venv проекта. Эфирный пайплайн для сборки сайта не запускается. Шрифт и аудиодемо встроены в HTML, лицензия шрифта сохранена.

Старая облачная функция, хранилище и ранее полученные заявки не удалялись. Их отключение и обработка накопленных данных — отдельная операция.

## Демонстрация звука
С 14.11.2026 на сайте отдельный вымышленный голосовой пример: условные улицы, балл и задержки. Это не дорожные данные Ижевска или другого реального города. Джинглов, музыки, подписи ведущего и звукового оформления станции в примере нет. Имена голоса и ведущего в плеере не указаны. Штатный голос SpeechKit используется только для демонстрации синтеза и не закрепляется как единственный вариант продукта.

Текст — оригинальный, создан для этого демо. Происхождение аудио и контрольная сумма хранятся в demo.json. Сгенерированный контент используется по условиям SpeechKit: https://yandex.ru/legal/cloud_terms_speechkit/ru/ (раздел 5.1, проверено 14.11.2026). Материалы станции не использованы в этом аудиопримере.

## Обработка данных
privacy.html — политика обработки обращений и описание технических данных хостинга. Ссылки находятся в подвале главной страницы, контактном блоке и на старой странице контактов thanks.html. Форм, флажков согласия и сторонних скриптов не добавлено.

Для изменений редактировать privacy-source.html и privacy-details.json, затем build.py. Сведения владельца, контактный email, адрес сайта и дата редакции задаются в privacy-details.json. При изменении способа работы с обращениями нужно обновить содержание политики. Автоматического удаления почты в коде сайта нет; описанные сроки хранения требуют соблюдения владельцем почтового ящика.
