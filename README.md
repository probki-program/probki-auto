# Сайт «Пробки»

Основной адрес с 18.11.2026: https://probki-program.netlify.app/.

Netlify связан с репозиторием probki-program/probki-auto: production branch — main, publish directory — корень репозитория (.), build command — пустой. На GitHub хранятся готовые файлы, Netlify публикует обновления автоматически. Используется бесплатный тариф Free; в нём может отображаться значок Powered by Netlify.

В корень репозитория публикуются index.html, thanks.html, privacy.html, FONT-LICENSE.txt, README.md, .nojekyll и assets/demo-<hash>.mp3. Прежняя публикация GitHub Pages (main, /(root)) пока сохранена.

С 14.11.2026 форма заменена блоком прямой связи через probkiauto@gmail.com. Кнопки «Обсудить подключение» открывают контакты. Ссылка mailto открывает почтовое приложение посетителя; сайт не отправляет заявку и не подтверждает доставку письма.

SmartCaptcha, запросы к Cloud Functions и сохранение заявок из сайта удалены. Сторонние скрипты не подключаются. Файл thanks.html оставлен для старых ссылок и показывает контакты без сообщения об успешной отправке.

Для изменений редактируйте исходники и запускайте build.py через Python из .venv проекта. Эфирный пайплайн для сборки сайта не запускается. Шрифт встроен в HTML, лицензия сохранена. Готовый MP3 находится в assets/ и загружается по запросу посетителя.

Старая облачная функция, хранилище и ранее полученные заявки не удалялись. Их отключение и обработка накопленных данных — отдельная операция.

## Демонстрация звука
С 17.11.2026 на сайте вымышленный пример с джинглом и музыкальной подложкой владельца проекта. Джингл звучит в начале, затем идёт сводка поверх музыки и короткое затухание. Улицы, балл и задержки условны. Это не дорожные данные Ижевска или другого реального города.

Текст и голосовая часть сохранены из демо 14.11.2026. Штатный голос SpeechKit используется для демонстрации синтеза и не закрепляется как единственный вариант продукта. При обновлении новый синтез не выполнялся. Джингл и подложка предоставлены владельцем проекта отдельно от материалов станции.

Для повторной сборки звука: mix_demo.py; для сборки страниц: build.py. Запускать через существующий Python из .venv проекта. Происхождение, параметры сведения и контрольные суммы сохранены локально в AUDIO-ORIGIN.md и demo.json. MP3 — 320 kbps, 44.1 kHz, стерео. Аудио хранится на том же сайте, без внешних плееров или сервисов генерации в браузере.

## Обработка данных
privacy.html — политика обработки обращений и описание технических данных хостинга. Ссылки находятся в подвале главной страницы, контактном блоке и на старой странице контактов thanks.html. Форм, флажков согласия и сторонних скриптов не добавлено.

Для изменений редактировать privacy-source.html и privacy-details.json, затем build.py. Сведения владельца, контактный email, адрес сайта и дата редакции задаются в privacy-details.json. При изменении способа работы с обращениями нужно обновить содержание политики. Автоматического удаления почты в коде сайта нет; описанные сроки хранения требуют соблюдения владельцем почтового ящика.
